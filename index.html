Configurações

Planilha do LG (Drive)

Cole o link ou o ID da Google Sheet do LG. Vale para todo mundo que usa a aplicação — não precisa mexer em código.

URL do Apps Script — testar só neste navegador

Isso não muda a URL para as outras pessoas — é só uma forma de testar uma implantação nova antes de editar o index.html e publicar no GitHub de verdade (que aí sim vale para todo mundo).

Incluir colaborador

Para quem não vem no export do LG (PJ, estagiário, consultor fixo etc.). Fica salvo numa aba separada e não é apagado quando a base do LG for atualizada.
